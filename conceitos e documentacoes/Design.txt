Tipografia & Formas

    Fonte: Inter ou Poppins (Sans-serif, moderna).

    Bordas (border-radius): 16px a 20px (Bem arredondado, estilo "bolha").

    Sombras: Suaves e difusas (0 4px 20px rgba(0,0,0,0.4)), para dar profundidade no modo escuro.

UX Patterns (Comportamento)

    Feedback Visual: Todo clique deve ter resposta (ex: botão escurece levemente no :active).

    Input de Valor: Deve ser o destaque visual (fonte grande) na hora de lançar transações.

    Empty States: Se não houver dados (ex: nenhuma conta criada), mostrar uma ilustração simples ou texto amigável com um botão para criar.

🛠 3. Especificação das Telas (Wireframes Lógicos)

Aqui descrevo o que compõe cada tela para você montar os componentes React.
Tela 1: Dashboard (A "Home")

Já detalhamos anteriormente, mas recapitulando o fluxo:

    Objetivo: Visão rápida da saúde financeira.

    Componentes Chave:

        Header: Seletor de Mês.

        Resumo: 3 Cards (Saldo Total, Receitas, Despesas).

        Carrossel de Contas: Scroll horizontal rápido.

        Lista Recente: As últimas 5 transações.

    Ação Principal: Botão Flutuante (FAB) + fixo no canto inferior direito.

Tela 2: Modal de Nova Transação (Feature: Lançamento)

Esta é a tela mais usada. Deve ser um Modal do Bootstrap centralizado.

    Cabeçalho: Título "Nova Transação" + Botão Fechar (X).

    Toggle de Tipo: Um componente visual (estilo Segmented Control) no topo.

        [ Receita (Verde) ] | [ Despesa (Vermelho) ]

        UX: Ao clicar em Despesa, o botão de "Salvar" lá embaixo fica vermelho. Se Receita, fica verde.

    Input de Valor: Gigante e centralizado.

        Ex: R$ 0,00 (Use uma biblioteca de mask como react-number-format).

    Formulário (Inputs Padrão Bootstrap Dark):

        Descrição: Texto curto (ex: "Pizza").

        Categoria: Select (Dropdown) listando as categorias cadastradas.

        Data: Datepicker (Default hoje).

        Conta de Origem/Destino: Select (Dropdown) listando as contas criadas (ex: Nubank, Carteira).

    Footer:

        Botão "Cancelar" (Texto cinza).

        Botão "Confirmar" (Largo, cor sólida dependendo do tipo).

Tela 3: Meus Extratos (Feature: Listagem Completa)

Uma versão expandida da lista do dashboard.

    Header: Título "Transações" + Barra de Busca + Filtro.

        Filtro: Um dropdown simples para filtrar por "Somente Receitas", "Somente Despesas" ou "Por Categoria".

    Conteúdo:

        Uma tabela ou lista de cards. Sugiro Lista de Cards (igual ao Dashboard) para manter o visual "Mobile Friendly" e Pop.

        Agrupamento por Data (ex: Um cabeçalho pequeno dizendo "Ontem", "Hoje", "20 de Nov").

    Interação:

        Clicar em um item abre um modal para Editar ou Excluir a transação.

Tela 4: Minhas Contas (Feature: Gerenciamento de Contas)

Onde o usuário cria e edita suas carteiras.

    Header: Título "Minhas Contas" + Botão "Nova Conta".

    Grid de Cards:

        Cards retangulares mostrando: Ícone do Banco/Tipo, Nome da Conta, Saldo Atual.

        Botões de ação pequenos dentro do card (Ícone de Lápis para editar, Lixeira para excluir).

    Modal de Criação/Edição de Conta:

        Input: Nome da Conta (ex: "NuBank").

        Input: Saldo Inicial (Para quem está começando agora e já tem dinheiro lá).

        Input opcional: Cor do cartão ou Ícone.

Tela 5: Categorias (Feature: Categorização)

Gerenciamento das "etiquetas" das despesas.

    Layout: Lista simples com ícones coloridos.

    Lista:

        Ex: [Ícone Burger] Alimentação (Ações: Editar/Excluir).

        Ex: [Ícone Bus] Transporte.

    UX Importante:

        Já vir com categorias padrão cadastradas (Alimentação, Casa, Lazer, Transporte, Salário).

        Botão "Nova Categoria" abre um modal pequeno pedindo Nome e uma Cor (Color Picker simples).
